STYLE SYSTEM (apply to every image, never deviate)

No readable words, numbers, logos or brand names anywhere in the frame. No real company or product logos. No fake certificates, badges, awards or seals.

## How the set will be wired into the site

| File | Page / component | Slot |
| --- | --- | --- |
| about-hero, approach-hero, nationwide-support-hero, contact-hero | `PageHero` aside on those pages | 16:9, `priority` on load |
| service-*.jpg | `services/[slug]` hero aside; 3:2 crop on the services hub and mega-menu feature card | `next/image`, responsive sizes |
| industry-*.jpg | `industries/[slug]` hero aside; 3:2 crop on `IndustriesList` | same |
| texture-* | `CTASection` and `GovernmentBand` backgrounds at 20 to 30 percent opacity | decorative, empty alt |
| og-default | fallback Open Graph image | replaces the generated OG only if preferred |
| case-study-placeholder | `CaseStudyCard` when no client image exists | decorative |

## What this set deliberately does not include

- Team headshots or "our engineers" portraits. Generated faces presented as staff would be a fabrication on a trust-focused site. Real photos of real people go in `site.people` when supplied.
- Customer logos, partner badges, certification seals, award graphics. Those come only from verified sources per `docs/client-information-required.md`.
- Anything with readable text. Image models garble text and readable fake text is a credibility risk.

## Alt-text rule when wiring

Informational images get a one-sentence description of what is shown. Textures and backgrounds get `alt=""`.

## Upload path

Drop finished files into `celestino-enterprise-web/public/images/` in the GitHub repo (branch `claude/celestino-enterprise-rebuild-3obrp3`) using the exact filenames. The site detects each file at build time; anything missing simply does not render.
